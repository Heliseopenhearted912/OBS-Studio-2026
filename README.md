# 📡 tweet-radar - Filter X with your own rules

---

## 🚀 What Is tweet-radar?

tweet-radar is a free Chrome extension that helps you find valuable posts on X (formerly Twitter) without scrolling endlessly. Instead of letting the algorithm decide what you see, you set your own rules. The extension scans posts and shows you only the ones that match your interests.

It uses a smart AI system called TypeSafe AI to understand what makes a post worth reading. The best part? The rules themselves are open source, meaning anyone can see how they work and even improve them.

---

## 🎯 Why Use tweet-radar?

X is a massive stream of information. Most posts are noise. A few are gold. tweet-radar helps you separate the two.

Here is what you get:

- **Your rules, your feed** - Tell tweet-radar what you care about. It does the rest.
- **AI-powered filtering** - The extension understands context, not just keywords. A post about "Apple" the fruit and "Apple" the company are treated differently.
- **Open source rules** - The judgment system is transparent. You can see exactly why a post was shown or hidden.
- **Free forever** - No paid tiers, no hidden costs. Just download and use.
- **Privacy-friendly** - Everything happens in your browser. Your data stays with you.

## 🛠️ How to Install tweet-radar (Windows)

Now that you have the ZIP file, you need to install the extension into Chrome. Follow these steps carefully.

### Step 1: Extract the ZIP File

Right-click on the ZIP file and choose **"Extract All..."** from the menu. Windows will ask you where to save the extracted folder. Just click **"Extract"** to use the default location.

After extraction, you will see a new folder named `tweet-radar-main`. This folder contains the extension.

### Step 2: Open Chrome Extensions Page

Open Google Chrome. In the address bar at the top, type this exactly:

`chrome://extensions`

Then press Enter. You will see a page with all your installed extensions.

### Step 3: Turn on Developer Mode

Look at the top-right corner of the extensions page. You will see a switch that says **"Developer mode"**. Click it so it turns blue. This reveals hidden buttons on the page.

### Step 4: Load the Extension

Click the button that says **"Load unpacked"** (it appears after you enable Developer mode). A file explorer window will open. Navigate to the `tweet-radar-main` folder you extracted earlier. Select that folder and click **"Select Folder"**.

Chrome will install the extension immediately. You will see tweet-radar appear in your list of extensions.

### Step 5: Pin the Extension

Click the puzzle piece icon in the top-right corner of Chrome (near your profile picture). Find tweet-radar in the list and click the pin icon next to it. This places the extension icon in your toolbar for easy access.

## 🎉 How to Use tweet-radar

Using tweet-radar is simple.

### First Launch

Click the tweet-radar icon in your browser toolbar. A small popup window will open. It will show you a welcome message and a few sample rules.

### Setting Your Rules

To create a rule, click the **"Add Rule"** button. You will see a text box. Type what you want to see. For example:

- `posts about artificial intelligence`
- `news from reliable sources`
- `tips for learning Spanish`

You can also set rules to hide content. For example:

- `posts with too much jargon`
- `sensational headlines`

### Browse X Normally

Now just go to X.com and browse as you normally would. tweet-radar works in the background. Posts that match your rules are highlighted. Posts that do not are dimmed or hidden.

### Adjusting Rules Over Time

Your tastes change. Your rules can change too. Open the popup window anytime and edit, add, or remove rules. The AI learns from your adjustments and gets better over time.

## 💡 Tips for Better Filtering

Here are some suggestions to get the most out of tweet-radar:

- **Be specific** - Instead of "tech", use "AI news" or "software development"
- **Use multiple rules** - A single broad rule catches less than several focused ones
- **Combine positive and negative rules** - Tell it what to show AND what to hide
- **Start simple** - Begin with 2-3 rules. Add more as you understand the tool.

## 🐛 Troubleshooting

If something does not work, try these fixes:

### The Extension Does Not Appear

- Make sure you extracted the ZIP file completely
- Check that you selected the correct folder (not the ZIP file itself)
- Restart Chrome after loading the extension

### Posts Are Not Being Filtered

- Make sure you are logged into X.com
- Refresh the page after adding new rules
- Try a simpler rule to test if it works

### Chrome Says "Manifest File Missing"

- You probably selected the wrong folder. Make sure you select `tweet-radar-main`, not the ZIP or a subfolder inside it.

### Uninstalling

To remove tweet-radar, go to `chrome://extensions`, find tweet-radar, and click **"Remove"**.
